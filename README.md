# Augentis Nexus — Clickable Prototype

**Live prototype:** https://abe-augentisai.github.io/augentis-nexus-prototype/

A click-through walkthrough of the Augentis Nexus embedded finance
marketplace: banks publish productized API services, fintechs subscribe in
one click, and AugentisLabs delivers the rest via the 5D Framework with
pre-built AI capability modules.

Navigate like the real product — click the persona switcher in the top bar
(Bank / Fintech / AugentisLabs), the sidebar, and the cards. Arrow keys step
through all 15 screens; every screen is hash-linkable.

**Everything shown is seeded fiction.** No real institutions, people, PII,
or functional credentials.
